# Snooze Button Roast

One line, at most 200 characters: roast the snooze button.

Entry: `My snooze button and I have an understanding: I press it nine times, it pretends to be surprised, and we are both late together.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
